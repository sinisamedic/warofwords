Before the adventure

A few useful answers.

When can I play?

The Android version is in development. The official Google Play link will appear on this page when it is available.

Can I play offline?

Campaign and Daily Challenge practice work offline. Ranked daily challenges and online leaderboards need an internet connection.

Is this a browser game?

War of Words is being made for Android. This website introduces the game. You can find GottaPlay’s browser games at gottaplay.net.

Are there ads or purchases?

The current preview has no advertising SDK or in-app purchases. An optional rewarded-ad continuation for Endless mode is being considered. Final launch details will be published before that feature is introduced.
